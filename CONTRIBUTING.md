# Contributing

By submitting a pull request, you certify that you wrote the code yourself and that it is contributed under this project's Apache 2.0 license.

## AI Usage

Using AI tools is allowed, but only as an aid to your own thinking, not as a substitute for it. Before submitting, you should be able to explain every part of your changes: what the code does, why it is structured that way, and what edge cases were considered. If you cannot, the PR is not ready.

You are fully responsible for what you submit, regardless of how it was written, AI assisted or not. It must be maintainable and something you can stand behind.

## General Guidelines

Keep changes focused. One feature or fix per PR makes review faster and keeps the history clean. If you are unsure whether something is a good fit for the project before investing time writing it, open an Issue first.
